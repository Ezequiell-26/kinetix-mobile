# 🏆 KinetixFitt — Competitive Ranks System

**Sistema de Rangos Competitivos con Distribución Percentil**

---

## 🎯 CONCEPTO

Un sistema de **12 rangos competitivos** que motiva a los usuarios mostrándoles su posición relativa (percentil) en la comunidad global. Inspirado en sistemas ranked de esports (League of Legends, Valorant, CS:GO).

**Filosofía:** Mientras más activo sos, mejor rango tenés. Los rangos más altos son **exclusivos** (top 1%, top 5%, etc).

## 📈 ACTIVITY SCORE (0-10,000 puntos)

El **Activity Score** determina tu rango. Se calcula con múltiples factores:

### Factores que Suman Puntos

1. **Workouts Completados** (hasta 2,000 pts)
   - 10 pts por workout
   - Máximo: 200 workouts

2. **Racha Actual** (hasta 1,000 pts)
   - 15 pts por día consecutivo
   - Máximo: ~67 días

3. **Mejor Racha** (hasta 500 pts)
   - 10 pts por día de tu mejor racha
   - Máximo: 50 días

4. **Volumen Total** (hasta 1,500 pts)
   - 1 pt por cada 100 kg levantados
   - Ejemplo: 150,000 kg = 1,500 pts

5. **Consistencia** (hasta 1,500 pts)
   - % de días con workout (últimos 30 días) × 15
   - 100% consistencia = 1,500 pts

6. **Personal Records** (hasta 1,000 pts)
   - 20 pts por PR
   - Máximo: 50 PRs

7. **Achievements** (hasta 1,000 pts)
   - 25 pts por achievement
   - Máximo: 40 achievements

8. **Challenges Completados** (hasta 800 pts)
   - 30 pts por challenge
   - Máximo: ~27 challenges

9. **XP Total** (hasta 500 pts)
   - 1 pt por cada 10 XP
   - Máximo: 5,000 XP

10. **Workouts por Semana** (hasta 400 pts)
    - Promedio últimas 4 semanas × 50
    - 8 workouts/semana = 400 pts

**Total Máximo:** 10,000 puntos

## 🔧 IMPLEMENTACIÓN TÉCNICA

### 1. Calcular Score
```typescript
import { calculateActivityScore } from "@/lib/competitive-ranks";

const score = calculateActivityScore({
  workoutsCompleted: 120,
  currentStreak: 25,
  longestStreak: 45,
  totalVolume: 75000,
  consistency: 0.85,
  prCount: 12,
  achievementsUnlocked: 18,
  challengesCompleted: 8,
  totalXP: 2500,
  daysActive: 90,
  avgWorkoutsPerWeek: 4.5,
});

// score = ~5,200 pts → PRIME rank
```

### 2. Obtener Rango
```typescript
import { getRankByScore } from "@/lib/competitive-ranks";

const rank = getRankByScore(5200);
// rank.nameES = "Prime"
// rank.percentile = "Top 15%"
```

### 3. Mostrar Progreso
```typescript
import { getProgressToNextRank } from "@/lib/competitive-ranks";

const { current, next, progress, pointsNeeded } = getProgressToNextRank(5200);
// current = Prime
// next = Titan
// progress = 30%
// pointsNeeded = 300 pts
```
