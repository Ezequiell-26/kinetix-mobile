## 📝 NOMBRE DE MARCA

### Forma Correcta ✅

**KinetixFitt**
- K mayúscula
- F mayúscula
- Todo junto, sin espacio
- Mayúsculas intercaladas (camelCase)

### Usos Correctos

```
✅ "KinetixFitt es la plataforma..."
✅ "Descarga KinetixFitt hoy"
✅ "Únete a KinetixFitt"
✅ "KinetixFitt - Transform Your Fitness Journey"
✅ "Bienvenido a KinetixFitt"
```

---

## ❌ ERRORES COMUNES

### Formas INCORRECTAS

```
❌ KINETIXFITT (todo mayúsculas)
❌ kinetixfitt (todo minúsculas)
❌ Kinetixfitt (solo primera mayúscula)
❌ KinetixFITT (más de dos mayúsculas)
❌ Kinetix Fitt (separado con espacio)
❌ Kinetix-Fitt (con guión)
❌ kinetix fitt (minúsculas separadas)
```

### Cuándo usar variantes

#### Versión Completa: **KinetixFitt**
Usar en:
- Títulos principales
- Headers de app
- Landing page hero
- App Store listings
- Marketing materials
- Email signatures
- Contratos/documentos oficiales

#### Versión Corta: **Kinetix**
Usar en:
- Espacios limitados (favicon text)
- Notificaciones push cortas
- Mensajes de chat informales
- Referencias casuales en blog

#### Versión URL/Code: **kinetixfitt**
Usar SOLO en:
- URLs (kinetixfitt.com)
- Package names (npm: kinetixfitt)
- Handles sociales (@kinetixfitt)
- Variables de código (const kinetixfitt)
- Email addresses (support@kinetixfitt.com)
- Git branches (feat/kinetixfitt-rebrand)

## 💬 CONTEXTOS DE USO

### En Oraciones

#### Inicio de oración
```
✅ "KinetixFitt te ayuda a alcanzar tus objetivos"
❌ "kinetixfitt te ayuda..." (nunca minúscula al inicio)
```

#### Medio de oración
```
✅ "La app de KinetixFitt es increíble"
✅ "Usa KinetixFitt para trackear"
❌ "Usa kinetixfitt para..." (incorrecto)
```

#### Con artículos
```
✅ "Descarga KinetixFitt" (sin artículo)
✅ "La plataforma KinetixFitt" (con artículo antes)
❌ "Descarga el KinetixFitt" (no usar "el" directo)
```

### En Títulos

#### Headlines
```
✅ "KinetixFitt: Transform Your Fitness"
✅ "Por Qué KinetixFitt Es Diferente"
✅ "Comienza con KinetixFitt Hoy"
```

#### Meta titles (SEO)
```
✅ "KinetixFitt - Fitness Coaching Platform"
✅ "Dashboard | KinetixFitt"
✅ "Login - KinetixFitt App"
```

### En Código

#### Variables TypeScript
```typescript
// ✅ CORRECTO
import { BRAND } from "@/config/branding";
const appName = "KinetixFitt";
const brandName = BRAND.name; // "KinetixFitt"

// ❌ INCORRECTO
const appName = "KINETIXFITT";
const appName = "kinetixfitt";
```

#### HTML/JSX
```tsx
// ✅ CORRECTO
<title>KinetixFitt - Dashboard</title>
<h1>Bienvenido a KinetixFitt</h1>

// ❌ INCORRECTO
<title>KINETIXFITT - Dashboard</title>
<h1>Bienvenido a kinetixfitt</h1>
```

#### CSS Classes (usar kebab-case)
```css
/* ✅ CORRECTO */
.kinetixfitt-header { }
.kinetixfitt-btn { }

/* ❌ INCORRECTO */
.KinetixFitt-header { }
.KINETIXFITT-btn { }
```
